# Financial Performance Dashboard — Tableau

## 📊 Project Overview

The **Financial Performance Dashboard** is an interactive Tableau dashboard designed to analyze and visualize business financial performance.

The dashboard provides a consolidated view of **revenue, profit, profit margin, sales trends, and product-category performance**, helping users understand financial trends and identify areas of strong or weak performance.

---

## 🎯 Project Objectives

* Analyze revenue performance over time
* Analyze profit performance over time
* Compare revenue across product categories
* Compare profit across product categories
* Analyze sales/revenue trends
* Evaluate profit margins by product category
* Create meaningful financial KPIs
* Build an interactive and professional Tableau dashboard
* Present financial information in an easy-to-understand format

---

## 🛠️ Tools & Technologies

* **Tableau**
* **CSV Dataset**

## 📂 Dataset

The project uses a structured financial/customer dataset containing fields related to:

* Date
* Year
* Customer information
* Product Category
* Product Sub-Category
* Revenue
* Profit
* Other business-related attributes

The dataset was verified and cleaned before being used for analysis and visualization.

---

## 🧮 Calculated Measures

Five key financial calculations were created and verified:

1. **Total Revenue**
2. **Total Profit**
3. **Total Quantity**
4. **Average Revenue**
5. **Profit Margin**

These calculations were used to support the dashboard KPIs and financial analysis.

---

## 📈 Dashboard Visualizations

The final dashboard contains six major visualizations:

### 1. Revenue by Year

Shows how revenue changes across different years.

### 2. Profit by Year

Displays yearly profit performance and helps identify changes in profitability.

### 3. Revenue by Product Category

Compares revenue generated by different product categories.

### 4. Profit by Product Category

Compares profit contribution across product categories.

### 5. Sales/Revenue Trend

Shows the overall sales/revenue trend over time.

### 6. Profit Margin by Category

Compares profitability across product categories using profit margin.

---

## 📌 Dashboard KPIs

The dashboard includes three major KPI cards:

* **Total Revenue**
* **Total Profit**
* **Profit Margin**

These KPIs provide an immediate overview of overall financial performance.

---

## 🎛️ Interactivity

The dashboard includes interactive filters and controls that allow users to explore the financial data and analyze different segments of business performance.

Users can use the dashboard to examine trends and compare performance across relevant categories and time periods.

## 🔍 Key Business Questions

The dashboard helps answer questions such as:

* How is revenue changing over time?
* How is profit changing over time?
